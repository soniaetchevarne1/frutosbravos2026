# Sonia - Tienda de Alimentos Saludables

Este es el proyecto de la tienda online para "Sonia", desarrollado con tecnologías modernas para asegurar velocidad, diseño premium y facilidad de uso.

## 🛠️ Tecnologías Usadas
- **Next.js**: Framework de React para producción.
- **TypeScript**: Para mayor seguridad y calidad de código.
- **CSS Modules**: Estilos personalizados sin frameworks pesados.
- **Lucide React**: Íconos modernos y limpios.

## 🚀 Cómo iniciar la aplicación en tu PC

Sigue estos pasos para ejecutar la tienda en tu computadora:

### 1. Requisitos Previos
Asegúrate de tener instalados:
- [Node.js](https://nodejs.org/) (Versión 18 o superior).

### 2. Abrir el proyecto
Abre una terminal (PowerShell, CMD o Terminal de VS Code) y navega a la carpeta del proyecto:

```bash
cd "C:\Users\marma\OneDrive\ARCHIVOS\SONIA APP\web"
```

### 3. Instalar dependencias
Si es la primera vez que lo abres, ejecuta:

```bash
npm install
```

### 4. Iniciar el servidor
Ejecuta el siguiente comando para iniciar la tienda:

```bash
npm run dev
```

### 5. Ver la tienda
Una vez que veas el mensaje "Ready in ...", abre tu navegador favorito e ingresa a:

[http://localhost:3000](http://localhost:3000)

## 📂 Estructura del Proyecto

- **/src/app**: Contiene todas las páginas (Inicio, Tienda, Carrito, Admin).
- **/src/components**: Componentes reusables como la Barra de Navegación y el Footer.
- **/src/lib**: Datos de ejemplo (productos, ventas) y configuraciones generales.
- **/public**: Imágenes y archivos estáticos.

## ✨ Funcionalidades Incluidas
- **Tienda Minorista y Mayorista**: Precios diferenciados según el tipo de cliente.
- **Carrito de Compras**: Agregar productos, ver resumen y calcular envíos.
- **Checkout**: Formulario de finalización de compra.
- **Blog y Recetas**: Contenido dinámico con opción de comprar ingredientes.
- **Panel de Admin**: Vista básica de ventas y gestión de productos.
