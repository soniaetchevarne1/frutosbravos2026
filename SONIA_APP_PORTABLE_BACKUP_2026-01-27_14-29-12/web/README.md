# Fruto Bravo - Tienda Online

## Deployment

This project is ready to be deployed on Vercel, Netlify, or any Next.js-compatible hosting platform.

### Quick Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/fruto-bravo)

1. Push your code to GitHub
2. Import your repository in Vercel
3. Vercel will auto-detect Next.js and deploy
4. Add your custom domain in Settings → Domains

### Environment Variables

No environment variables are required for basic functionality.

### Build Commands

- **Build**: `npm run build`
- **Start**: `npm run start`
- **Dev**: `npm run dev`

### Custom Domain Setup

After deployment:
1. Go to your project settings
2. Add your custom domain
3. Follow DNS configuration instructions
4. Wait for SSL certificate provisioning

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
